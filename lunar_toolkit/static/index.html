Data and indexes

Build downloads the cumulative CUMINDEX.TAB (EDR about 3.8 GB) and writes the Parquet with DuckDB; "Volume index only" uses one release's INDEX.TAB (about 20 k rows). Update appends the volumes released since the build. Same as lunar build-db.
